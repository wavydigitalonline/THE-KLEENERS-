# The Kleeners — Static Website

Professional pest control & hygiene website for **The Kleeners** (Centurion).

## Features

- Responsive single-page site (HTML / CSS / JS)
- Vertical Instagram-style video reels (autoplay when in view + native controls)
- Quote request form with the fields requested:
  - Bedrooms
  - Free-standing / complex / apartment / business
  - Business sqm
  - Location
  - Pest type
- Form submits via WhatsApp with structured message
- Floating WhatsApp button
- Google reviews section (5.0★ · 77+)
- Services, why-us, gallery, contact

## Deploy to GitHub Pages

1. Create a new repo (e.g. `thekleeners`)
2. Upload everything in this folder to the root of the repo
3. Settings → Pages → Source: `main` branch / root
4. Site will be live at `https://YOURUSER.github.io/thekleeners/`

Or connect a custom domain (`thekleeners.co.za`) in Pages settings.

## Edit content later

- Copy & contact details: `index.html`
- Styles: `css/styles.css`
- Form / video behaviour: `js/main.js`
- Images: `assets/images/`
- Videos: `assets/videos/`
